# Space Trainer

GTA V single player trainer (.asi)

- Open/close: **F5**
- Author: [xdigr](https://t.me/xdigr)
- Version: 3.5.1
- License: GPL-3.0 (see LICENSE.txt / COPYING.txt)

## Install

1. ScriptHookV + ASI Loader in the GTA V folder
2. Turn off BattlEye in Rockstar Launcher
3. Copy `Space.asi` and `SpaceStuff` next to `GTA5.exe`
4. Start Story Mode, press F5

SP only. Don't use this in Online.

## Build

Windows + VS 2022 (C++):

```
git clone --recursive https://github.com/networkgpts/Space-Trainer-GTA-5.git
cd Space-Trainer-GTA-5
build.bat
```

Output: `Solution/source/_Build/bin/Release/Space.asi`
